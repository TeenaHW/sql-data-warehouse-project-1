## 🗂️ Project Structure
 
###  Data Warehouse (Data Engineering)
 
**Objective:** Build a modern data warehouse on SQL Server to consolidate sales data and support analytical reporting.
 
**Key Specifications:**
- **Sources** — Two CSV based systems: ERP and CRM
- **Data Quality** — Cleansing and issue resolution before loading
- **Integration** — Unified, analytics friendly data model from both sources
- **Documentation** — Clear data model docs for business and technical stakeholders
